# MiniMax Web Tool (MMX) - 使用说明指南

欢迎使用重构后的 MiniMax Web 工具，本工具现已**完整覆盖官方 `mmx` CLI 的所有高级生成与查询功能**。

## 1. 启动项目

```bash
pnpm install
pnpm run dev
```

在浏览器中打开 Vite 提供的本地链接即可使用。

## 2. 界面布局

当前网页采取了**三栏式布局**：
- **左侧边栏**：功能导航条，点击可切换至不同的工具面板。
- **中间区域**：工作台。在这里进行参数输入、启动生成以及预览结果。
- **右侧面板**：全局执行日志（Execution Logs）。您的每一次点击，都会在这里以流式日志的形式追踪请求发送、成功、失败的详情与原始 Payload。

## 3. 功能操作说明

### ⚙️ 设置与配额 (Settings)
- 首次使用必须在此面板输入您的 `MINIMAX_TOKEN`。
- 输入后，您可以点击 `Check Quota` 按钮，并在下方或右侧日志面板中实时查看您的账户使用额度。

### 🔍 联网搜索 & 👁️ 图像理解
- 与首个版本体验一致。您可以进行实时互联网信息搜索和图片的深度语义分析。

### 💬 文本对话 (Chat)
- 支持单论会话（文本聊天）。键入内容后回车或点击按钮即可。

### 🖼️ 图像生成 (Image)
- 键入对于画面的详细描述，模型将为您生成一张精美的图片。返回的数据中包含了可供访问的图片 URL 链接。

### 🗣️ 语音合成 (Speech)
- 输入一段需要转换的文本，调用 `speech-01` 模型，合成包含情感变化的真人语音数据。

### 🎬 视频生成 (Video)
- 在提示词中描述镜头的运动、主体的动作等，即可生成具有电影质感的短视频。

### 🎵 音乐生成 (Music)
- 输入想要的音乐风格，如果有具体的歌词也可以填入第二个选填框，系统将生成符合韵律的原创音乐。

## 4. 日志追踪
无论您是在生成一首歌还是一段视频，由于生成大模型通常响应耗时较长，我们强烈建议您在操作后，将视线移至**右侧日志大屏**。您会清晰地看到 `[INFO] Starting xxx generation...`，如果网络或 Token 出错会立刻亮起红色的 `[ERROR]`，成功后则会亮起绿色的 `[SUCCESS]` 日志，点开日志内部可以看到带有资源下载链接的原始返回数据。
